Participantes: Kauã Leguissamon da Silva - Raul Babeto Barbosa - João Gabriel Barz

tema: Controle Pessoal

resumo: O projeto tem como objetivo criar uma api aonde o usuario pode controlar o seu gastos e ganhos do mes, sendo um controle pessoal para finanças no qual permite registrar receitas e despesas, acompanhar o saldo em cada conta do cliente e sendo possivel consultar o saldo da conta por periodo

requisitos funcionais: listar as contas do usuario com o saldo atual dele.

permitir registrar um lançamento informando a conta, categoria valor e data

permitir consultar o extrato por periodo

permitir cadastrar,editar,excluir categorias e contas


requisitos não funcionais: ser responsivo

comunicação com o backend

indicar estados de carregamentos

ser organizado em componentes reutilizaveis.
